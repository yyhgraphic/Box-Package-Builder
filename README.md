## Box Package Builder

[👉 Box Package Builder 바로가기](https://github.com/yyhgraphic/Box-Package-Builder)

### 프로젝트 설명
Box Package Builder는 패키지 디자인 작업 중 형태와 비율을 빠르게 확인해 볼 수 있는 중간 점검용, 웹 기반 디자인 툴입니다.
업로드한 이미지가 각 면에 자동 배치되며, 광택/모서리 둥글기/조명 세기 등을 슬라이더로 조절하여 원하는 질감과 분위기를 연출할 수 있습니다.

### 주요 기능
* **이미지 레이아웃 배치**: 큐브의 6개 면에 비율 그대로 자동 배치, 드래그로 면 간 이미지 교체
* **카메라**: 카메라 뷰 이동
* **모션**: 턴테이블 방식의 자동 회전, 2배속 재생
* **패키지 표면 효과**: 광택, 모서리 둥글기, 조명 세기, 반사광 색상
* **캔버스**: 배경 색상 변경, 해상도 직접 지정
* **파일 내보내기**: PNG 이미지 및 MP4 비디오 파일 저장
